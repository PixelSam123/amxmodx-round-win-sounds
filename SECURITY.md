# Security policy

## Reporting a vulnerability

Please report security issues privately through GitHub's
[private vulnerability reporting](https://github.com/PixelSam123/amxmodx-round-win-sounds/security/advisories/new)
(Security -> Advisories -> Report a vulnerability). If that is unavailable,
open an issue that describes the problem **without** including server
credentials, IP addresses, or player data.

## Scope

This plugin does not make network requests, write configuration files, or
handle credentials. The most likely issues are a server crash or malformed
menu/sound input. Only the latest release is supported with security fixes.
